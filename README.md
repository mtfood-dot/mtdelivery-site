# MT Delivery – البريد السريع

Site vitrine de MT Delivery, livraison de colis à Meftah (Blida) et dans les 69 wilayas.

- `index.html` : page unique bilingue FR/AR (tarifs, inscription expéditeur, demande d'argent COD, avis, réclamation).
- Tarifs modifiables en haut du `<script>` : `TARIFS.local` et `WILAYAS`.
- Hébergé sur Netlify, déploiement automatique à chaque modification de la branche `main`.
